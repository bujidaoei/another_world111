## User Scenarios & Testing *(mandatory)*

### User Story 1 - 有准备、有取舍的单人远征 (Priority: P1)

玩家从营地选择补给和路线，在废弃泵站街区战斗、采集和判断撤离时机，带回资源改善下一次准备。
首个原型用真实规则贯通一条循环；基础几何体明确标记，不能冒充最终视觉。

**Why this priority**: 优先验证资源风险和战斗操作是否产生有意义的选择，避免先堆内容。
**Independent Test**: 从新档开始完成一次成功撤离和一次失败重试，包含开始、操作、暂停、结算、保存退出、重新加载。

**Acceptance Scenarios**:

1. **Given** 可离线启动的新档，**When** 出营、战斗和采集后撤离，**Then** 只有真实获得资源进入结算且回营后可使用。
2. **Given** 不同准备和路线，**When** 面对同种危险，**Then** 选择影响消耗、风险或收益，玩家能通过状态/反馈辨认。
3. **Given** 遭遇进行中，**When** 暂时离开仇恨范围，**Then** 仍不能应用配置或获得营地操作资格。
4. **Given** 失败、退出或存档异常，**When** 重启，**Then** 按已冻结失败与存档规则恢复，不能静默重置有效进度。

### User Story 2 - 培养一件有经历的装备 (Priority: P1)

玩家用融合、独立扩槽和进阶培养早期稀有装备，选择锁定与材料消耗，并知道随机结果不会保证提升。

**Why this priority**: 培养是探索收益的主要去向，必须证明可解释、合法且值得取舍。
**Independent Test**: 从合法装备/资源快照复现融合、扩槽、进阶及拒绝路径；快照只在测试使用，实际游戏获取路径另外跑通。

**Acceptance Scenarios**:

1. **Given** 两件符合条件装备，**When** 锁定至多2条并确认融合，**Then** 材料消耗一次，未锁槽随机重抽，主身份/特效/经历/槽数不变。
2. **Given** 4槽主装备，**When** 独立扩槽，**Then** 旧词条保留，新词条合法，总上限与天然5槽一致。
3. **Given** 世界资格不足或无合法候选，**When** 尝试培养，**Then** 明确拒绝且无部分扣费/装备丢失。
4. **Given** 正在营地但未结束遭遇，**When** 融合或切配置，**Then** 操作仍被拒绝。

### User Story 3 - 晋阶带来新的操作与探索 (Priority: P1)

玩家在等级门槛完成个人挑战，从一阶闪电枪三目标连锁过渡到二阶导电锚点，回到旧区获得新用途，并进入新区域。

**Why this priority**: 证明成长改变玩法，而不只是数值膨胀。
**Independent Test**: 自己达到等级门槛、积累超额经验、挑战失败后重试、胜利晋阶、布锚点连接分散目标；全程单人可完成。

**Acceptance Scenarios**:

1. **Given** 一阶等级30，**When** 继续获得经验但未胜利挑战，**Then** 等级停30、经验积累且不发31级天赋点。
2. **Given** 挑战胜利，**When** 正式结算，**Then** 只写一次晋阶记录，开放二阶资格并处理积累经验。
3. **Given** 二阶资格，**When** 使用原闪电枪进阶和锚点，**Then** 装备经历/槽数保留，操作和视觉发生可读变化。
4. **Given** 切角色或预设，**When** 合法应用，**Then** 无免费治疗、资源补充或冷却刷新。

### User Story 4 - 原创场景中舒适操作 (Priority: P2)

玩家在移动和战斗中辨认角色、敌人、危险、互动和路线，雨水、机械、植被、暖光与声音构成一致的废土氛围。
PC与后接Android采用同一规则；键鼠/手柄/触控操作分别验证。

**Independent Test**: 相同场景在具名设备上完成完整流程，审查遮挡、UI消费、镜头、视听、性能、存档与恢复；真人观察另列证据。
**Acceptance Scenarios**: 自由/固定镜头与一键恢复均可操作；画质降级不删除危险信息；菜单输入不触发世界动作；媒体和模型通过实际游戏内审查。

### User Story 5 - 合作提前发现新可能 (Priority: P3，后续评估)

低阶玩家在高阶地图发现新武器类型，但奖励与能力仍属自己的境界。
**Independent Test**: 只有合作另立规格并冻结网络/适配方案后才执行跨阶真实双客户端测试。
**Acceptance Scenarios**: 高低阶个人奖励、挑战记录、解锁和交易资格独立；输出/生存/治疗/控制参与有实际规则与证据。

### Edge Cases

- 等级门槛前后大量经验、重复结算、切角色重复奖励、挑战失败后重试。
- 融合装备自选作材料、已装备材料、超过2锁、重复/互斥候选、候选耗尽、非法预算、资源不足、连点确认。
- 短暂脱战、营地边界、Boss尚未重置、预设引用不存在装备、最大生命变化、切疗愈角色绕过恢复冷却。
- 多指镜头/摇杆/技能冲突，输入设备切换、失焦、返回键、暂停与后台恢复。
- 截断/损坏/迁移失败、连续保存、写入中结束、权限/空间不足；不得清除最后有效存档。
- 首次六目标事件在只实现一至二阶的版本不会生成；后续三阶事件真实发生后才记录。

## Requirements *(mandatory)*

### Functional Requirements

“P0”表示本轮阶段 0；“P1/P2”是后续实现优先级，不表示本轮已实现；“后续”保留完整产品规则但不进入首个原型。

- **REQ-001**（P0）: 真实核查工程、Git、工具、MCP、Skills、依赖与设备，记录成功、失败及未测试；不覆盖已有工作。 → AC-001
- **REQ-002**（P0）: 用 Spec Kit 正式初始化并建立宪章、规格、计划、检查表、任务、分析、变更和进度。 → AC-002
- **REQ-003**（P0）: 整理事实、设计建议、待决策项、原创生产路径、双端验证与阶段门槛，交付指定GitHub仓库。 → AC-003
- **REQ-004**（P1）: 提供离线单人探索：开始、移动、战斗、采集、负重/补给取舍、任务、撤离、回营、失败、重试的连续循环。 → AC-004
- **REQ-005**（P1）: 个人世界等级和已通过境界共享给同世界进度的角色；初始一阶每30级设置挑战节点。 → AC-005
- **REQ-006**（P1）: 晋阶同时带来新区域、旧地图用途和新的战斗操作；单人能完成挑战和获取全部内容。 → AC-006
- **REQ-007**（P1）: 装备阶级独立于稀有品质；品质能给机制但不得突破个人境界、阶级强度及培养资格。 → AC-007
- **REQ-008**（P1）: 随机普通词条最多5条；同类型/阶级/品质整体预算相当，4槽单条更高、5槽组合更多；培养5槽与天然5槽上限一致。 → AC-008
- **REQ-009**（P1）: 融合仅营地且遭遇结束：一主一料，同阶/品质/部位，武器同类型；最多锁2条；未锁位置从双方合格普通池随机抽取。 → AC-009
- **REQ-010**（P1）: 融合金币固定相同，阶级材料另算，锁定材料另算；成功不保证更强。 → AC-010
- **REQ-011**（P1）: 扩槽为独立操作：对应阶级材料确定4至5，保留旧词条并随机新增合法词条，适当增加总预算；装备进阶不扩槽不提品质。 → AC-011
- **REQ-012**（P1）: 闪电枪一阶连锁3目标；二阶解锁导电锚点，改变连接分散敌人的操作；技能按个人境界限幅。 → AC-012
- **REQ-013**（后续）: 三阶闪电枪雷网/绯红分支各有代价，不能通过融合、珠宝、共鸣同时获得完整专属能力；真伤额度和成本受阶级限制。 → AC-013
- **REQ-014**（P1）: 装备保留首次地点/关卡/时间、进阶地点/时间、首次六目标连锁和分支选择经历。 → AC-014
- **REQ-015**（P1）: 世界等级增长发天赋点；角色分别保存配置，查看编辑不受场所限制，应用统一营地+遭遇结束。各角色是否按共享总量独立配置是D-005待冻结解释，确认后按决定执行，不能提前视为用户同意。 → AC-015
- **REQ-016**（后续）: 共鸣节点满足分支点数与装备/技能阶段阈值才生效，不授予未解锁高阶能力或抹去分支取舍。 → AC-016
- **REQ-017**（P1）: 每角色3套流派预设保存天赋、技能装配、装备分支；只在营地且遭遇结束应用。 → AC-017
- **REQ-018**（P1）: 角色共享公共解锁、等级、境界，分别保存装备/技能/天赋/预设；通用武器技能所有角色可用，专属能力不能转移。 → AC-018
- **REQ-019**（后续）: 外观由游玩解锁，只改变造型/动作视觉，不改变属性、攻击判定、动作生效时机和强度。 → AC-019
- **REQ-020**（后续评估）: 合作可提前发现装备类型，但奖励阶级、经验和培养遵守个人境界；不替个人晋阶或开放区域。 → AC-020
- **REQ-021**（后续评估）: 合作跨境界需真实战斗适配和参与贡献规则，让低阶参与且个人上限持续；断线和奖励重复有确定规则。 → AC-021
- **REQ-022**（P1）: 3D斜俯视跟随镜头支持有限旋转/缩放、自由/固定模式和一键默认恢复；固定前可调整，锁定后跟随。 → AC-022
- **REQ-023**（P1）: 横屏触控、键鼠和手柄共享规则，分别适配移动、瞄准、攻击、闪避、防御、技能与交互。 → AC-023
- **REQ-024**（P1）: 提供启动、加载、暂停/恢复、设置、音量、字号、抖动/闪烁控制、语言与失焦/后台恢复。 → AC-024
- **REQ-025**（P1）: 存档保护唯一有效版本，定义版本、校验、备份、迁移、失败反馈及恢复，保存成功需重新校验。 → AC-025
- **REQ-026**（P2）: 代表性原创角色、场景、动作、VFX、UI、音频先确立样本，再生产；保留源文件与许可记录。 → AC-026
- **REQ-027**（P2）: 可游玩画面、材质、模型、动态、氛围整体优于参考；以可比较实机证据验证。 → AC-027
- **REQ-028**（P1）: 采集、制作和营地建设使用真实资源，至少一个营地设施具有可验证的补给或制作作用；生存资源影响远征准备与撤离。 → AC-033

### Non-functional Requirements

- **NFR-001**（P1）: 规则、输入、实体、UI、配置、存档、音频、平台和日志边界清晰；配置有校验与错误恢复。 → AC-028
- **NFR-002**（P2）: 性能在具名设备、场景和画质下采样分位帧时、长帧、内存、加载和热稳定性，优化依据测量。 → AC-029
- **NFR-003**（P1）: 用分层自动化、完整流程、真机、真人验收及缺陷回归证明；零测试、失败、跳过不能报告通过。 → AC-030
- **NFR-004**（全部）: 安全认证，无源码/日志/历史凭据；第三方依赖及资产许可、版本和再分发明确。 → AC-031
- **NFR-005**（发布）: 干净检出可复现获取依赖、导入、测试和构建；Windows/Android产物、CI及交接证据分别交付。 → AC-032

### Key Entities *(include if feature involves data)*

- 世界进度：共享世界等级、境界、经验储备、天赋总量、晋阶/区域/公共解锁。
- 角色配置：装备、通用技能、专属身份、天赋草稿/生效配置、3套预设、持续冷却和外观。
- 装备实例：身份、阶级、品质、槽数、普通词条、固有效果、分支、强化及不可伪造经历。
- 遭遇：开始至胜利/失败/撤离且重置的状态；短暂脱战不结束。
- 资源与操作事务：采集/奖励/材料、固定融合金币、重复确认与合法性。
- 存档：格式版本、世界和角色进度、资源、设置、校验、备份与恢复信息。
- 资产与证据：源工程、许可、采用版本、工具记录、构建和具名设备/真人验证。

## Success Criteria *(mandatory)*

### Measurable Outcomes

以下AC是应达标准，未附游戏证据均未通过。阶段 0 只验收 AC-001 至 AC-003 的当前范围及安全文档检查。

| --- | --- |
| AC-001 | 报告包含实际调用、版本、路径、返回和限制；三份核心工件与事实一致。 |
| AC-002 | 官方CLI初始化成功，Codex skills和脚本真实存在，关联检查成功；未来功能不勾选。 |
| AC-003 | 方向与确认记录可查，任务有证据；本地提交、推送和远端SHA分别报告。 |

| AC-005 | 等级30且未挑战时不升31；超额经验保留；挑战胜利一次性开放二阶和31—60，切角色不重复发点。 |

| AC-007 | 一阶稀有及高阶普通均合法；非法高阶使用/强化/技能被拒绝，交易亦不能绕过。 |
| AC-008 | 生成和每次培养无重复/互斥/超预算/超单条上限；明确数值配置和边界用例。 |
| AC-009 | 确认前可见候选、条件概率、锁定和全成本；材料一次性消耗；身份、槽数、阶级/品质/特效/分支/经历不变，材料特效不转移。 |
| AC-010 | 所有阶级/品质/槽数/锁数对应相同金币价；无合法候选/资金不足/重复确认不能产生半扣费或消失装备。 |

| AC-012 | 实际命中3目标与布点跨距连锁有不同输入和反馈；未晋阶玩家不能用锚点；模型和VFX有辨识变化。 |

| AC-014 | 实际事件产生记录，未发生事件不伪造；融合材料不覆盖主装备记录；重载后经历一致。 |
| AC-015 | 未获得/超预算点不可应用；换角色不增共享总点；查看和编辑不影响战斗生效配置；独立配置的点数解释D-005冻结后另写具体边界用例。 |
| AC-016 | 游走导体/蓄雷护体/断链聚能分别测试阶段与阈值，未满足时禁用；组合上限明确。 |
| AC-017 | 短暂脱战/躲避不允许切换；切换保留生命比例，不补资源、不刷新冷却，新上限截断资源。 |
| AC-018 | 切角色只在营地且遭遇结束；专属治疗冷却持续且同类恢复共享防绕过；盗窃者5%只作用本玩家怪物金币；疗愈者可自疗。 |

| AC-020 | 地图限定类型，个人限定装备/珠宝/材料阶级；高低阶各自结算，交易资格检查；经验上限和个人挑战记录保持。 |
| AC-021 | 输出/生存/治疗/控制/奖励均有跨阶规则，合作实测且无超阶能力；网络评估后独立规格冻结再实现。 |
| AC-022 | 三输入下能调角度和缩放、固定/解锁/恢复；菜单不误触镜头；遮挡与旋转眩晕有实际检查。 |
| AC-023 | 设备切换、菜单焦点、重映射、辅助瞄准与死区有规则；触控多指和UI消费不触发世界动作；真机任务独立未完成前不报双端通过。 |
| AC-024 | 完整流程含暂停与设置持久化；生命资源冷却遵循暂停定义；窗口/DPI/返回/通知恢复分别验证。 |
