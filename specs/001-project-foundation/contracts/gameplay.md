# 玩家命令与状态契约（设计）

这是未来实现/测试约束，未建立空API。无外部网络接口；命令以类型明确的本地调用落地。

| 操作 | 前置条件 | 成功后状态 | 拒绝/反馈 |
| --- | --- | --- | --- |
| BeginExpedition | 有有效进度、准备配置合法 | 创建远征/遭遇与真实资源状态 | 无效配置/保存异常明确提示 |
| Move/Aim/Attack/Dodge/Defend/Skill | 游戏运行，输入未被UI消费；动作/资源/冷却合法 | 正确时刻动作、命中、消耗、事件 | 无资格/资源不足提示；不绕过冷却 |
| Evacuate | 允许撤离、到撤离点并满足交互过程 | 完成重置后Ended；合法战利品结算一次 | 短暂躲避不视为撤离结束 |
| Ascend | 等级门槛及个人挑战胜利 | 新realm、区域/资格、记录一次；处理储备经验 | 未胜利不升境界不发下一阶段天赋 |
| PreviewFusion | 不同实例+同阶/品质/部位/武器类型、≤2锁、camp+Ended | 返回候选、条件概率、全部成本、规则版本 | 无合法结果/无资源/非法锁全部拒绝，不扣费 |
| CommitFusion | 预览版本和物品/资源未变，资格重验 | 主装备合法成品，材料删除和扣费一起提交 | 连点/状态变化不重复提交；主特效/槽数/经历保持 |
| ExpandSlots/AdvanceEquipment | camp+Ended，对应材料和境界合法 | 独立扩槽或进阶，约束不同 | 操作必须区分、不得顺带升品质/槽数 |
| ApplyBuild/SwitchCharacter | camp+Ended、资格/点数/引用合法 | 生命比例、资源上限、持续/同类恢复冷却保持 | 不允许脱战伪结束或半应用 |
| SetCameraMode/ResetCamera | UI消费正确、设置合法 | 自由/固定、锁定仍跟随、一键默认 | 菜单动作不同时攻击或拖镜头 |
| Save/Load | 格式与容量合法 | 回读校验后成功，或有效备份恢复 | 错误码和玩家反馈，保留有效槽及原始文件 |

动作返回状态：Success/Rejected/Failed，提供稳定错误码和必要上下文；不以异常当合法拒绝，不静默丢弃错误。
界面草稿与已生效配置分离；预览是只读，确认仍重验。核心事件包括遭遇结果、资源变更、装备成长、世界晋阶和存档结果。
输入映射、时序、数值均由经过校验的配置提供，不能写到UI按钮回调中。
