## User Scenarios & Testing
### User Story 1 - 单人远征 (Priority: P1)
在营地制备补给，进入雨庭，移动瞄准、闪避防御、连锁电击，采集有限资源，完成真实目标任务，选择继续或撤离。
独立测试：新档成功一次、失败一次，暂停/保存退出/重启恢复；击杀/采集/任务/金币/材料均真实结算且不可重复领。
### User Story 2 - 晋阶与培养 (Priority: P1)
真实积累等级到30，个人守卫挑战成功才能进入二阶，保留同一电枪身份并进阶，用导电锚点连接分散敌人及进入二阶区域。
独立测试：等级上限/储备经验/失败重试/重复晋阶；融合/扩槽/进阶预算、槽数、特效与经历守恒。
### User Story 3 - 原创表现与可靠恢复 (Priority: P2)
角色/敌人/设施/雨水/光色有可读表现，界面显示状态/目标/成本，输入不漏入游戏，设置与进度可靠持久。
独立测试：原生PC完整输入/运行、GdUnit核心/存档、实际GodotMCP/BlenderMCP/ComfyMCP工具证据；Android/手柄/真人不伪通过。

## Requirements
### Functional Requirements
- **REQ-101**: 原生离线启动、主菜单、新档/继续、暂停/设置、完整远征/失败/撤离/重试/恢复。 → AC-101
- **REQ-102**: 移动、瞄准、攻击、闪避、防御、通用冲击技能、交互/采集/药包；UI优先消费，三输入适配与镜头自由/固定/复位。 → AC-102
- **REQ-103**: 两敌人职责/守卫真实预备与命中、遮挡与距离判定；一阶总3目标电链，二阶锚点资格/布点/跨距链。 → AC-103
- **REQ-104**: 真实任务kill3+采集2节点，击杀6XP/2金币，任务60XP/12金币/3废铁；个人30节点/储备/晋阶记录幂等。 → AC-104
- **REQ-105**: 远征负载18，金币无重量；XP即得，战利品回营入库，失败丢pending；制作药包/购买口粮/营地设施真实成本与作用。 → AC-105
- **REQ-106**: 稀有/普通、阶级/品质分离，4/5槽预算100/120（t2×1.5）、单条35，融合固定12金币+对应材/锁材；合法随机条件概率、身份/特效/经历不转移；扩槽/进阶独立。 → AC-106
- **REQ-107**: 双有效槽v2，checksum含header与精确payload，1MiB、JSON安全校验、回读成功、错误反馈、坏槽恢复、未来版本阻写、v1回归迁移。 → AC-107

CR-004（2026-10-13）扩充REQ-102/107：键盘绑定以独立数据配置、冲突检测与菜单保留键实现；全局设置和键位使用独立双槽preferences目录，标题尚未开始游戏也持久。偏好缺失不能创造游戏进度，损坏/未来格式不能被默认值覆盖。Slider保存延迟合并，正常退出/返回立即刷新。PC改键与提示验证归TEST-107，存储异常归TEST-106。
- **REQ-108**: 原创建模源/GLB及制作记录、Godot粒子/材质/光照MCP、合法本地Comfy图像产物、Playwright官方资料/素材许可研究。 → AC-108
### Non-functional Requirements
- **NFR-101**: 核心规则独立RefCounted、场景/输入/UI/存档分层；配置校验、信号生命周期、版本/错误日志与无服务秘钥。 → AC-109
- **NFR-102**: GdUnit4发现非零，失败/错误/必需跳过阻断；真实PC流程、分位性能、原型质量和外部验收分别记录。 → AC-110

### Key Entities
AWGameRules、AWWorldProgress、AWInventoryLedger、AWExpeditionState、AWEquipmentService、SaveRepository；
运行时角色/敌人/锚点/采集点、保存设置/生命/资源/当前装备、合法掉落实例和产物来源。

## Success Criteria
| AC | 验收 |
| --- | --- |
| AC-101 | 可执行构建从新档运行成功远征/失败重试/暂停/退出恢复，无卡死/假奖励；待真实验证 |
| AC-102 | PC动作与UI/镜头实测，触控/手柄适配有技术证据但缺设备时不报设备验收 |
| AC-103 | 三目标、障碍、动作时序、二阶锚点实际可玩且边界测试 |
| AC-104 | 新档真实任务/击杀升30，挑战失败不晋阶、成功一次记录/新区域/经验处理；测试夹具另列 |
| AC-105 | 负载/成本/设施/死亡与撤离守恒，可重载保持且不能重复结算 |
| AC-106 | 单条/总预算/互斥/槽数/阶级资格、最多2锁与精确预览、材料消耗一次、原经历/特效保护测试通过 |
| AC-107 | 正常/损坏/截断/中断/权限/容量/连续/旧格式/未来格式测试，无有效存档被静默清除 |
| AC-108 | 每个工具真实执行与产物，实际GLB导入/图像采用；商业品质/优于参考仍需后续评审 |
| AC-109 | 正确版本真实导入运行无脚本错误，配置非法明确失败；模块边界及日志检查 |
| AC-110 | 非零GdUnit报告与明确预期失败/零发现测试，PC完整流程和测量；未有真人/Android不标通过 |

## Edge Cases
重复领奖/操作、候选耗尽、超锁/超预算、同装备作为材料、营地但未结束遭遇、脱战误认Ended；
攻击穿墙/死目标、技能与UI触控冲突、后台清输入、损坏/未来存档、生命周期对象释放。

## Assumptions
原型与完整产品不同；三阶分支/共鸣/珠宝/多角色/预设/合作/正式内容在后续独立规格继续实现。
目前不引入收费外部服务，不用SDK模型许可未知输出发布；真实Android/手柄/真人门槛保持开放而非停止独立制作。
