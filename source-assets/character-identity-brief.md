# 阶段003：盗窃者与疗愈者原创身份样本

关联003 REQ-201/203、NFR-203、AC-201/203/213、TASK-222及ADR-022/025。两件原创代表模型/骨架动作现已实际制作、导出并通过源/二进制/固定Godot导入检查；真实主工程游戏内辨识、动作事件、性能、设备和最终商业品质仍待验收。实际交付清单为 `character-manifest.json`，细节见 `characters-production.md`。

## 样本方向与玩法边界

两角色继续机械维修世界的原创机器人语言，使用同一库存电枪、相同基础生命/体力和相同实体判定。盗窃者5%只来自真实怪币结算，造型的精密回收夹与分类盒解释身份；疗愈者专属自疗通过维护器和循环管路解释，画面反馈只由真实成功施放触发。造型不添加隐身、偷窃攻击、额外武器、飞行或群体治疗能力。

区分顺序是头部/肩部/背部大形、身体明度分区、功能设备、少量颜色提示。灰度与低亮度下仍需辨认；两者不能仅靠青/橙换色。保留石墨结构、钢连接、橙色实用设备、米白绝缘和青色功能灯的同族职责；敌人锈红保持敌方辨识，不将它大面积用于主角。标记采用原创双条/开口括号结构，避免真实机构徽记。

| 维度 | thief 盗窃者 | healer 疗愈者 |
| --- | --- | --- |
| 主形 | 窄胸、前倾楔形短头、错位肩板 | 稍宽浅色躯干、圆角头、U形肩架 |
| 背部轮廓 | 偏置的两层分类盒，折叠夹沿一侧收纳 | 中央低矮圆盘循环器，两侧封闭短管路 |
| 功能设备 | 腰侧细密回收盒，手腕夹头收起，保持持枪手净空 | 胸前分段绝缘板，非持枪腕维护器与回流管 |
| 明度分布 | 深结构为主，头顶/前臂浅块帮助背景辨识，橙色中块 | 米白躯干/肩架为主，深关节/脚保持骨架方向 |
| 最高优先细节 | 侧盒大形和楔头，即使缩到40–60px仍要保留 | 圆盘背包/U肩架，浅深分区在侧后方仍可读 |
| 动作性格 | 短促检查视线，稳定双足交替，收纳件不穿躯干 | 平缓检查姿态，同样可靠的落脚；施放时维护腕朝胸部 |
| 资格反馈 | 真实怪币收益/余数和撤离确认由UI与声音表达，不制作假偷窃施放 | 自疗成功时维护器短促青/暖白点亮与局部环线；失败不播放成功表现 |

## 源工程实施安排

Blender MCP继续使用带项目标记的专用实例。为本轮建立独立 `AnotherWorld_CharacterIdentities` 场景，不能执行会清空当前District场景的旧全族脚本；建造前检查工程/场景所有权和对象共享。基础几何/材质工具抽取为有明确场景拥有者的可复用库，角色与世界建造脚本分别调用，不通过导入具有顶层删除副作用的旧脚本复用。

根协调激活003后的实际交付合同为源工程 `source-assets/blender/characters-v1.blend`、脚本 `source-assets/scripts/character_factory.py`，真实运行文件 `game/assets/models/thief_robot.glb`、`healer_robot.glb`。两件均存在且实际hash/尺寸/几何/动画已记录；旧拟定名称未作为空资产创建。`character-planned-manifest.json`保留原计划身份并指向真实清单，当前指标以实际清单为准。

实际制作先完成盗窃者代表轮廓、骨架与Idle/Walk，发现首姿势冻结后修复动作写入顺序、加入明确action求值审计，再完成同族疗愈者与成功自疗姿态。静态附属件合入单张蒙皮网格并赋所属骨刚性权重；导出前刷新依赖图测顶点边界，文件内资源/真实skin/关节/权重/动画逐项读取。这里是真实机械骨架蒙皮，权重为刚性部件，不能宣称人体软组织变形或最终动作品质。

ComfyUI本轮没有任务提交。后续若需要角色材质细粒样本，先围绕已定表面职责在本地固定官方模型/许可/种子生产，记录纯着色与正常/粗糙度用途；模型继续与游戏包分离。任何重型生产先协调真实游戏采样窗口，不并发污染性能证据。

## 游戏内样本门禁

1. 固定工具链真实导入两GLB，Root相同挂点/同电枪/同位置切角；当前菜单与角色变化由真实身份状态驱动，不用颜色替换冒充两个模型。
2. 在1280×720以及实际目标窗口无标签/无技能覆盖的同位图中辨认头、背部和明度方向；同场加入近战/发射机/守卫对照，灰度只是辅助检查。真人、Android和手柄门槛仍独立。
3. 真实Idle/Walk/闪避/防御/持枪/自疗成功与资格失败录制，脚部无滑步、附件无明显穿插、动画转回移动可靠；只看源棚内预览不能通过。
4. 自疗成功对应实际体力35与生命比例变化，专属20秒/恢复家族20秒资格明确；失败无成功环线/音效，切角/调槽/暂停不制造重复反馈。事件源归角色/共享CombatState，不由模型自身重施业务。
5. 原共享材质不被命中或身份切换污染，区域遮挡生命周期沿002修复模式；正常进程切角、换区、保存退出重载无引擎错误，资源随拥有者正确释放。
6. GLB/源审计和同场景增加成本有报告，最终美术质量与当前性能不凭计划预算报通过；TASK-222只有其全部规定源/许可/游戏内门槛满足才勾选。
