# 原创原型声音

使用 `generate_audio.py` 的数学合成生成全部15个WAV，无外部录音、采样包、模型输出或付费服务。代码、旋律、音色组合和PCM文件为本项目原创源资产，供本项目制作及商业发行使用；没有第三方样本许可或署名要求。并未将资产发布为公共领域或自动采用第三方授权。

制作范围：12个事件文件（electric/impact各两种变体，其余单个）、12秒雨声循环、80 BPM/D小调/8小节/24秒的音乐底层与战斗节奏层。雨声采用可重复噪声、周期滤波和细小滴水共振；音乐是代码编写的原创和弦/音符与打击合成。首尾校正避免循环突变，所有写入文件重新打开检查格式和波形数据。

复现：在仓库根执行 `python source-assets/audio/generate_audio.py`。仅使用Python标准库，实际运行版本和脚本/产物SHA256记录于 `manifest.json`。输出只能位于本仓库中。脚本没有访问网络或任何凭据。

`game/presentation/game_audio.gd` 提供5个命名总线、8个有优先级的固定音效voice、AudioStreamSynchronized双音乐层、遭遇状态淡入及主总线HardLimiter。settings沿项目正式字段独立控制音量；0是真静音。整体峰值预算保留余量，limiter只是额外保护。

`audio_probe.gd` 是复制到独立本地Godot项目的真实技术探针：加载WAV、建立总线、实际播放、音乐层淡入/淡出、8并发抢占、loop实际跨边界以及AudioEffectCapture读取Godot混音。Dummy音频驱动只提供技术验证，不代表真实扬声器/耳机试听、主游戏最终混音或商业声音品质。

当前声音明确为原创原型样本。最终仍需在游戏中试听与调整层间比例、重复疲劳、动作同步、耳机和扬声器表现。
